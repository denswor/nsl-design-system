# Checkbox

Checkbox with label. States: unchecked, checked, indeterminate, error, disabled.

- Props: `label`, `checked` / `defaultChecked`, `onChange(checked)`, `indeterminate`, `size` = `md` (20px box, 16px text) | `sm` (16px box, 14px text), `error`, `disabled`, `name`, `value`.
- Use `sm` in filters and configurator rows. Use CheckboxGroup for a labelled set.
