# NumberStepper

Quantity input with minus / plus buttons.

- Props: `value` / `defaultValue`, `onChange(number)`, `min` (default 0), `max`, `compact` (the 20px inline version used inside ConfiguratorRow), `disabled`.
- On a contrasting surface (ConfiguratorRow), the compact stepper's disabled buttons keep the surface text color at 50% opacity instead of turning grey.
