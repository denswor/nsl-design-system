# SectionHeader

Heading for a block of a page: Mono title, an optional count, and a "View all" link or controls on the right.

- Props: `title`, `count` (shown after the title in `text-secondary`), `action` = `{label, href}` (a Link with an arrow), `children` (controls on the right: Select, Toggle), `size` = `lg` (default, `heading-lg` 24/32) | `xl` (`heading-xl`, page section H2) | `md` (`heading-md`, inside a card), `as` = `h2` (default) | `h3`, `id` (anchor target).
- Use for grouped search results (Products 34, Articles and solutions 5, Site pages 12) and for any listing block with a "View all".
- Sections sit `space-48` to `space-64` apart; the header sits `space-16` above its content.
