# TopNavItem

One item of the header's gradient top bar: Mono 12 uppercase, bold with underline when active.

- Props: `href`, `active`, label as `children`. Used by Header; render it yourself only for a custom top bar.
- `menu`: a panel that opens under the item on hover or keyboard focus and closes on mouse leave (120ms delay) or Esc. Header puts CloudDropdown under Cloud.
