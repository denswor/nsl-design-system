# Logo

The NewServerLife logotype: gradient mark plus wordmark, or the mark alone.

- Props: `variant` = `full` (default) | `mark`; `tone` = `color` (default) | `white`; `height` in px (header uses 56, footer 48, mobile 28).
- `color` on white or `bg-subtle`; `white` on the brand gradient and dark bands. Never recolor the gradient or place the color logo on the gradient.
- Keep clear space of at least the mark's width on every side.
