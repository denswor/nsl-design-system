# Select

Dropdown select, single or multiple (Figma: Dropdown Trigger + Option Item = Dropdown).

- Props: `label`, `options` (strings or `{value,label,disabled}`), `value` / `defaultValue`, `onChange`, `multiple`, `placeholder`, `size` = `lg` | `md` | `sm`, `helper`, `error`, `disabled`, `open` / `defaultOpen`.
- Multiple shows checkboxes in the menu and joins labels in the trigger.
- Above 10 options or when users know what they want, add a search above the list instead.
