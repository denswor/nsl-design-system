# Tag

Compact label for categories, filters and "suitable for" lists.

- Props: `color` = `primary` | `secondary` | `success` | `warning` | `error` | `neutral` (default), `variant` = `filled` | `subtle` (default) | `outline`, `size` = `lg` | `md` (default) | `sm`, `iconLeft`, `iconRight`, `selected`, `disabled`, `onClick` (makes it a toggle button).
- Brand-colored tags are rare: they compete with the CTA. Default to `neutral`.
- For product availability and promotions use ProductBadge, not Tag.
