# Notification

Inline message banner on a tinted background (not a toast).

- Props: `type` = `default` | `success` | `warning` | `error` | `info`, `title`, `children` (message), `dismissible`, `onDismiss`, `icon` (override).
- Message first, then the fix: "Failed to save your configuration. Check your connection and try again."
- Configurator compatibility warnings ("High Performance fans are required when TDP exceeds 200W") are `warning`.
