# PriceRange

Price filter: from / to inputs joined above a range slider (Figma: Slider Compact Input).

- Props: `min`, `max`, `step`, `value` / `defaultValue` (`[from, to]`), `onChange`, `size` = `md` (40px inputs) | `sm` (32px, 14px text, for filter panels), `steps` and `snap` (passed to the slider).
