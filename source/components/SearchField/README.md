# SearchField

Site search box: placeholder "Search here...", search icon as the submit button.

- Props: `placeholder`, `value` / `defaultValue`, `onChange(value)`, `onSearch(value)` on Enter or icon click, `iconPosition` = `right` (default, submit button) | `left` (decorative), `disabled`.
- Header uses it at full remaining width. For predictive results, render your panel below it.
