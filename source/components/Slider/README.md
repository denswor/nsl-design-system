# Slider

Single value or range slider on a brand track.

- Props: `min`, `max`, `step`, `value` / `defaultValue` (a number, or `[low, high]` for a range), `onChange`, `steps` (dots at 0/25/50/75/100%), `valueLabel` (min/max under the track), `format(v)` for those labels, `disabled`.
- Pair with inputs (PriceRange) when the exact value matters.
